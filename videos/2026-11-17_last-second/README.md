# Последняя секунда (The Last Second)

Короткий sci-fi фильм: 43 с, 16:9, 24 fps, H.264 + AAC (−14 LUFS). Вся графика — реалтайм-3D (three.js) и собственные шейдеры. Звук — процедурная оркестровая партитура и SFX. Чужих видео, картинок и музыки нет.

- `last-second.mp4` — фильм 1920×1080 (рендер 1:1).
- `last-second_4k.mp4` — апскейл до 3840×2160 (lanczos + лёгкий unsharp). Это не нативный 4K-рендер, поэтому файл не в git: он больше 100 МБ.
- `index.html` — исходник: детерминированная сцена (`window.__seek(t)`), сама играет в браузере. Нужен локальный сервер, потому что ES-модули с `file://` не грузятся.
- `render_frames.cjs` — покадровый рендер (WebGL через SwiftShader, параллельные воркеры).
- `plan/PROMPTS_photoreal.md` — промпты для фотореалистичной версии (Veo / Sora / Kling / Runway). Тайминг совпадает, звук подходит без изменений.

## Планы
| Время | План |
|---|---|
| 0–5.4 с | Аэросъёмка мегаполиса на закате: солнце в конце проспекта, нырок между небоскрёбами к перекрёстку. Толпа идёт, один человек стоит. |
| 5.0–6.8 с | Время останавливается: тиканье часов ускоряется и обрывается. Люди замирают на полушаге, дождь становится висящими кристаллами, птицы замирают в воздухе. Камера продолжает двигаться. |
| 6.8–8.4 с | Макро глаза: двигаются только глаза героя, в конце он смотрит в объектив. |
| 8.4–16.4 с | Облёт героя на 360°: осколки стекла и капли висят в воздухе, машины всплывают. Небо трескается как зеркало, за ним космос. |
| 16.4–23 с | Асфальт превращается в прозрачный океан, город загибается вверх. Камера ныряет под воду, затем темнота. |
| 23–34.4 с | Открытый космос: Земля и чёрная дыра с гравитационным линзированием и аккреционным диском, рукава вещества затягивает внутрь. В тени дыры появляется силуэт старого героя и поднимает руку. Вселенная схлопывается в светящуюся сферу. |
| 34.4–38.85 с | Сфера оказывается галактикой в зрачке, камера отъезжает к макро глаза. Моргание, тьма, финальный удар. |
| 38.85–43 с | «ВРЕМЯ НИКОГДА НЕ ОСТАНАВЛИВАЛОСЬ. ЭТО ТЫ ЗАКОНЧИЛСЯ.» |

## Ограничения CG-версии
Это не фотореализм: люди — стилизованные фигуры в контровом свете, лиц крупным планом нет. Фотореалистичные кожа, лица и мимика требуют генеративной видеомодели или реальной съёмки, а здесь нет ни того ни другого, ни GPU. Для фотореалистичной версии используй `plan/PROMPTS_photoreal.md`.
