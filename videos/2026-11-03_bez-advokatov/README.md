# Что будет, если все адвокаты исчезнут

Ролик 51.8 с, 1920×1080, 60 fps, H.264 + AAC. Голоса нет: текст на экране, процедурная музыка и SFX. Сделан скиллом OBSION Motion.

- `bez-advokatov_final.mp4` — финал с озвучкой (88.2 с, 1080p60). Голос — ElevenLabs (`voice/vo_raw.mp3`); тайминги слов — `voice/words.json` (faster-whisper); микс — `voice/mix.sh`.
- `bez-advokatov_draft1.mp4` — первый черновик без голоса (52 с).
- `index.html` — исходник: детерминированная сцена (`?t=секунды` или `window.__seek(t)`), сама проигрывается в браузере.
- `plan/creative.md` — идея, запрещённые приёмы, сюрпризы, семя, три питча (выбран A).
- `plan/sources.csv`, `source-media/real/CATALOG.md` — все утверждения и откуда они взяты.

## Сюжет
1. 0–7 с — 75 813 адвокатов (ФПА, апрель 2025): поле из 758 фигурок, по 100 человек каждая. Их выдёргивают из листа, остаются дыры в форме людей.
2. 7–14 с — «Первым делом — убьём всех юристов» (Шекспир). Имя говорящего заклеено стикером.
3. 14–29 с — ты против следователя, прокурора и суда. Из Конституции (ст. 48) вырезают слово «адвоката». По УПК (ст. 51) защитник обязателен, и дела копятся.
4. 29–39 с — так уже было: Декрет о суде № 1 (1917) упразднил адвокатуру, в 1922-м её создавали заново. «Это фиаско, братан».
5. 39–47 с — стикер отклеивается: реплику говорит подручный мятежника Кейда в ответ на «когда я стану королём».
6. 47–52 с — адвокат возвращается в дыру рядом с тобой.
