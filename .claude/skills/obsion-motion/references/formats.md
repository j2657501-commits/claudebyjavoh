# Форматы: шесть быстрых плейбуков

Выбери формат, потом прочитай SKILL.md §1–§12. Числа ниже — стартовые, бриф пользователя важнее.

## 1. Вертикаль 9:16 (Reels / TikTok / Shorts), 1080×1920
- **Длина и хук:** 15–45 с; хук ≤ 1 с — движение и вопрос или нарушение ожидания на кадре 0.
- **Ритм:** 6–12 битов; смена каждые 1.5–3 с.
- **Безопасные зоны:** сверху 220 px, снизу 380 px (интерфейс платформы), по бокам 60 px.
- **Текст:** крупный, ≤ 5 слов на экране, субтитры по одной фразе.
- **Что резать:** всё, что не держит внимание на беззвучном просмотре. Ролик должен читаться без звука.

## 2. Реклама продукта / промо, 15–30 с
- **Схема:** проблема (2–3 с) → продукт решает её действием (основная часть) → выгода одной фразой → логотип и призыв (≤ 3 с).
- **Ритм:** 5–8 битов; один герой-объект через весь ролик.
- **Что резать:** список функций. Покажи одно действие, которое доказывает ценность.

## 3. Объяснялка, 30–90 с
- **Хук:** вопрос зрителя в первые 2 с.
- **Ритм:** одна метафора на тезис; 4–8 тезисов; перезахват внимания каждые 15–20 с.
- **Текст:** только ключевые слова; формулы и графики — по одному на экран.
- **Что резать:** вводные «давайте разберёмся». Сразу к действию.

## 4. UI-демо (продуктовая анимация), 15–40 с
- **Действие:** одна задача пользователя от начала до результата; курсор ведёт (`ui-motion.md`).
- **Ритм:** 3–6 действий; каждое = наведение → клик → смена состояния → результат.
- **Безопасные зоны:** текст UI ≥ 30 px на 1080p.
- **Что резать:** экраны без действия, повторяющиеся клики.

## 5. Интро / логотип, 3–10 с
- **Структура:** одна идея → сборка логотипа из действия (не «появление») → финальный кадр держится 0.5–1 с и всё равно дышит.
- **Звук:** один фирменный звук-подпись на сборке.
- **Что резать:** всё, что длиннее 10 с.

## 6. Данные / инфографика, 20–60 с
- **Структура:** одна цифра = один экран; рост и сравнение показаны движением (бар растёт, точки переливаются), а не таблицей.
- **Точность:** подписи и источники на экране; масштаб графика честный, ось с нуля, если это не сказано отдельно.
- **Что резать:** больше 3 рядов данных на экране.
