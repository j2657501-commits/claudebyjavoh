# Анимация интерфейса (продуктовое видео)

## Действие ведёт курсор
- Каждый эпизод — одна понятная задача: выбрать, перетащить, включить, запустить, получить результат.
- Цепочка: **наведение → реакция цели (hover) → нажатие (кнопка проседает на 2–4 %) → смена состояния → читаемый результат**.
- Курсор двигается по небольшой дуге 0.6–0.9 с с изингом; перед кликом короткая остановка 6–10 кадров. Попадание считается кончиком стрелки, а не центром картинки.
- Курсор не закрывает подпись кнопки, результат и цифры.

## Один правдоподобный интерфейс
- Одни данные и одни состояния на весь ролик; радиусы, тени и толщины линий единые.
- В одном действии выделено 1–3 главных контрола.
- Процесс показывай честно: прогресс → успех. Успех не появляется раньше конца процесса. Монтажное ускорение не выдаётся за реальную скорость.
- Демо-данные не выдаются за реальные метрики существующего сервиса.

## Drag & drop
- Зафиксировано смещение «курсор ↔ точка захвата».
- Карточка приподнимается (тень растёт, масштаб 1.03) и едет по дуге с лёгким запаздыванием.
- Зона назначения подсвечивается; при отпускании карточка встаёт в слот с пружиной. Соседи раздвигаются после события, а не одновременно.

## Один UI в 2D, 2.5D и 3D
| Режим | Что меняется |
|---|---|
| 2D | плоские панели; смысловой центр — действие курсора |
| 2.5D | те же панели разнесены по глубине; камера показывает слои, параллакс и перекрытия; боковин нет |
| 3D | у панелей и устройств настоящая толщина, кромка и боковые грани; свет и тени это подтверждают |

## Координаты
- Мировой UI и экранный оверлей разделены.
- Курсор, который работает с объектом в 3D-мире, берёт экранную точку из проекции якоря объекта с учётом камеры.
- Плашки у 3D-объектов следуют проекции без дрожания.
