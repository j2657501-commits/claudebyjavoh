# Ремесло движения: тайминг, изинги, пружины, текст, ритм

## 1. Тайминг (при 60 кадрах/с; в скобках — 24/30)
| Действие | Длительность |
|---|---|
| Микрореакция UI (hover, нажатие) | 0.12–0.2 с |
| Появление небольшого объекта | 0.3–0.5 с |
| Перемещение по кадру | 0.5–0.9 с |
| Крупное превращение, раскрытие сцены | 0.8–1.5 с |
| Подготовка (anticipation) | 15–30 % от длины действия, минимум 4 кадра (2–3) |
| Задержка вторичных частей (overlap) | 2–4 кадра на каждое звено цепи |
| Удар со стоп-кадром (hit-stop) | 2–4 кадра |
| Окно чтения слова | ≥ 0.4 с; фраза — 0.3 с на слово + 0.5 с |

Правила:
- Ничего не стартует одновременно: ступенька (stagger) 2–5 кадров между соседями, порядок по смыслу (от причины к следствию, от героя к фону).
- Чередуй быстрое и медленное. Ровный темп усыпляет; контраст скоростей и есть энергия.

## 2. Изинги
| Характер | GSAP | cubic-bezier |
|---|---|---|
| Уверенный вход | `power3.out` / `expo.out` | (0.16, 1, 0.3, 1) |
| Уход со сцены | `power2.in` | (0.5, 0, 0.75, 0) |
| Перемещение между точками | `power2.inOut` / `sine.inOut` | (0.65, 0, 0.35, 1) |
| Упругое появление | `back.out(1.6–2.2)` | (0.34, 1.56, 0.64, 1) |
| Пружина, вес | `elastic.out(1, 0.4–0.6)` или пружина (k 180, c 12) | — |
| Механика, техника | `steps(n)` / `power1` | — |

- Линейный изинг допускается только для постоянного вращения, конвейеров и камеры в середине пролёта (если путь задан сплайном).
- Не используй один и тот же изинг на всё: у тяжёлого и лёгкого разные кривые.

## 3. 12 принципов (как применять в коде)
1. **Сжатие-растяжение:** объём сохраняется, `scaleX·scaleY ≈ 1`; 8–20 % для мультяшного стиля, 2–5 % для премиального.
2. **Подготовка:** движение назад или вниз перед действием.
3. **Сценичность:** одна главная мысль в кадре, всё остальное тише (контраст, размер, резкость).
4. **Позы:** ключевые позы сильные и читаемые по силуэту, промежутки считает код.
5. **Доводка и захлёст (follow-through, overlap):** части продолжают движение после остановки корпуса; пружины.
6. **Разгон-торможение:** изинги, а не линейное движение.
7. **Дуги:** естественное движение идёт по дуге, а не по прямой (путь Безье или вращение вокруг удалённого pivot).
8. **Вторичное действие:** моргание, дыхание, реакция бутафории.
9. **Тайминг:** количество кадров задаёт вес и характер.
10. **Преувеличение:** эмоциональный пик на 20–30 % сильнее «реального».
11. **Объём:** у формы есть толщина, свет и тень.
12. **Обаяние:** герой с характером: асимметрия, особая походка, реакция в камеру.

## 4. Текст в действии
- Финальная раскладка сначала, потом анимация к ней.
- **Приёмы:**
  - маска строки (текст выезжает из-под линии);
  - побуквенная волна с stagger 1–2 кадра;
  - переменный шрифт (вес и ширина по времени);
  - слово физически толкает соседнее;
  - текст на объекте (привязан к его проекции);
  - кинетический удар на акцент (масштаб 1.15 → 1);
  - замена слова через «зачёркивание пером».
- Одно ключевое слово выделено цветом; у остальных одинаковая иерархия.
- Пока текст читается, камера ≤ 350 px/с и текст не уходит за край.

## 5. Ритм и удержание
- Новое событие или поворот каждые 3–5 с в коротком ролике.
- Кадр 0 уже движется; хук за ≤ 2 с.
- После пика дай 0.5–1 с «выдоха» (медленный дрейф), потом следующий удар.
- Финальная карточка живёт: последний акцент в последние 1–1.5 с, никакой 3-секундной статики.

## 6. Чистота кадра
- Пустые заготовки (белая рамка или табличка без содержимого) не висят дольше 0.3 с.
- Ничего не обрезано краем кадра, кроме намеренных пролётов.
- Края слоёв не видны.
- Контраст текста ≥ 4.5:1.
- Не больше 3 вспышек в секунду, без стробов.

## 7. Точные правила v1.1 (ресерч 19.10.2026: HyperFrames, Lottie, Remotion, iart-ai, Holden springs, WCAG)

### Пружины без интеграции
Пружина задаётся **формулой от времени**, поэтому перемотка детерминирована.

Критическое затухание с полураспадом h:
- y = 2·ln2 / h;
- x(t) = e^(−y·t)·(j0 + j1·t) + c;
- j0 = x0 − c;
- j1 = v0 + j0·y.

Перелёт при ζ < 1 равен exp(−πζ/√(1−ζ²)):

| ζ | перелёт |
|---|---|
| 0.4 | 25 % (резина) |
| 0.5 | 16 % |
| 0.7 | 4.6 % (бумага) |
| 1.0 | 0 % |

Для массы 1: ζ = damping / (2·√stiffness).

Пресеты (stiffness/damping):

| Характер | stiffness / damping |
|---|---|
| жёсткая | 400+/25–30 |
| стандарт | 250–350/18–24 |
| упругая | 150–250/10–15 |
| мягкая | 100–150/20–25 |

Полураспад вторичных частей:

| Часть | h, с |
|---|---|
| волосы | 0.12–0.25 |
| плащ | 0.2–0.35 |
| хвост | 0.15–0.3 |
| антенна / ухо | 0.08–0.15 |

### Масштаб — в логарифме
Зум камеры, поп карточки и раскрытие логотипа считай как s(p) = s0·(s1/s0)^p. Линейный масштаб ощущается ускоряющимся в конце.

### Подготовка, захлёст, вторичное
- **Подготовка:** 100–200 мс (3–6 кадров), 10–20 % амплитуды основного движения, в обратную сторону. Для микрореакций короче 150 мс не нужна.
- **Захлёст:** каждое звено цепи стартует на 1–2 кадра позже родителя. Хвосты останавливаются на 100–200 мс позже ведущего.
- **Вторичное действие:** 30–50 % амплитуды основного, старт на 50–100 мс позже, другой изинг. Например, карточка села, затем выросла её тень.

### Сжатие-растяжение и дуги
- **Сжатие** ≈ (1.2, 0.8), **растяжение** ≈ (0.85, 1.15).
- **Удар** 2–4 кадра, восстановление 4–8 кадров, объём в пределах 5 %.
- **Контакт** с землёй держи ≈ 5 % отскока. В премиальном стиле сжатия нет.
- **Дуга:** середина пути смещена перпендикулярно на 8–15 % длины. У механики пути прямые намеренно.

### Ступенька (stagger)
- Группа прибывает целиком ≤ 0.5 с.
- **Интервалы между элементами:**

  | Что | Шаг |
  |---|---|
  | списки | 40–60 мс |
  | сетки | 50–80 мс, +20 мс на ряд |
  | строки текста | 60–100 мс |
  | слова | 40–70 мс |
  | буквы | 20–40 мс |

- Полное раскрытие текста ≤ 0.8 с.
- **Порядок:** главный контент — от центра, списки — по порядку чтения.

### Смаз и параллакс
- **Смаз движения:**
  - затвор 180° (экспозиция = ½ кадра);
  - ≥ 8 подкадровых выборок, усреднение;
  - смазываются только 1–3 «удара» на ролик (рывок, разворот, поп);
  - не смазываются: медленный параллакс, фейды, читаемый текст;
  - подход к цели смазан, посадка резкая.
- **Параллакс считается, а не подбирается.**
  - Экранный сдвиг слоя = Δx·p/z.
  - Сверка соотношения ближний : средний : дальний ≈ 1 : 0.5 : 0.2, допуск ±30 %.
  - За каждым ближним слоем нужен запас фона Δx·p·(1/z_near − 1/z_far) пикселей.
  - Кадр в крайнем положении камеры проверяй на дыры.

### Переходы: дисциплина
- **Один основной переход** на 60–70 % смен сцен и 1–2 акцентных; самый смелый — на кульминацию. Разный переход на каждую сцену — это брак.
- **Уходящая сцена** полностью видна в начале перехода; отдельной анимации ухода нет, переход и есть уход.
- **Обе сцены движутся** с одного момента.
- **Наезд внутрь** окна или экрана — экспоненциальный (постоянная скорость в логарифме).
- **Глитч:** смещения — хэш от квантованного времени (8–12 Гц), длительность 2–6 кадров, потом картинка резко чистая.

### Звук и события
- **Один список событий** `EVENTS = [[сек, имя, аргумент], …]` управляет и картинкой, и звуком, поэтому разъехаться им некуда.
- **Атака SFX** ложится на кадр контакта или на 1 кадр позже, но не раньше чем на полкадра.
- **Рот** опережает звук на 1–2 кадра; остальное визуальное опережения не имеет.

### Липсинк для кукол
- **9 форм рта:**

  | Форма | Звуки |
  |---|---|
  | A | закрыт: П Б М |
  | B | приоткрыт, зубы: большинство согласных, И |
  | C | открыт: Э |
  | D | широко: А |
  | E | округлён: О |
  | F | трубочкой: У В |
  | G | зубы на губе: Ф |
  | H | язык: Л |
  | X | покой |

- Минимум 6 (A–F).
- Ни одна форма не держится короче 2 кадров.

### Взять предмет
1. Подготовка 3–6 кадров.
2. Кисть в точке хвата: ≤ 2 px до неё на кадре контакта.
3. В кадре контакта предмет переподчиняется кисти: локальное смещение = обратная матрица кисти × матрица предмета. Скачок в мире ≤ 0.5 px.
4. В руке предмет тянется на пружинке.
5. При отпускании предмет возвращается в мир и сохраняет скорость кисти.

### Эдит на скорости (velocity edit)
- **Перекартирование времени:** t_src = ∫speed.
- **Ключи скорости** стоят на долях, кривая плавная, диапазон 25–100 %+; самый медленный кадр приходится на бит.
- **Подкадровая выборка:** таймлайн свой, поэтому медленная часть считается по подкадровому времени без повтора кадров.
- **Вспышки-склейки** 2–6 кадров на восьмых долях.

### Безопасность вспышек
- Не больше 3 вспышек в любую секунду.
- Вспышкой считается пара противоположных перепадов яркости ≥ 10 %.

### Аудит скриптом
- Провал, если:
  - есть линейные пространственные твины;
  - семейств изингов меньше 3;
  - ступенька группы длиннее 0.5 с;
  - твинятся width/height/top/left (только transform/opacity).
- **Текст:** `scripts/layout_check.mjs` — текст за полями 5 %, перекрытия, контраст < 4.5, кегль < 30 px. Намеренные пролёты через объектив допустимы.
- **«Мёртвые» отрезки:** средняя покадровая разница < 0.4 дольше 1 с (`watch.py`, `holds.csv`).

## 8. Камера: дрейф — только пол
Дрейф 3–8 px на 0.04–0.13 Гц сдвигает кадр меньше чем на 1 px за 4 с; глазом это стоп-кадр. Видимая спокойная жизнь кадра = подъезд или отъезд ≥ 2.5 % за план + дрейф (`scripts/camlife.js`, `push: 0.03` по умолчанию). Проверка: паузы ≤ 0.5 с, средняя энергия движения ≥ 0.6.
