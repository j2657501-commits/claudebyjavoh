# Звук: музыка, SFX, карта акцентов, микс

**По умолчанию у каждого ролика есть звук:** музыка, SFX на каждое значимое действие и тихая атмосфера. Тишина только если её просили. Немой ролик — это недоделка, а не стиль.

## 0. Процедурный звук: `scripts/sfx.js` (детерминированно, без сэмплов и сети)
Один список событий управляет и картинкой, и звуком:
```js
const EVENTS = [[0,"riser",{dur:1.2}], [1.2,"impact",{size:1.2}], [1.25,"whoosh",{dur:.5,pan:[-.8,.8]}], [1.9,"pop"], [2.5,"paper",{dur:.5}]];
// анимация читает EVENTS (контакт, пролёт, поп), звук — тот же список:
window.__audioWav = async () => SFX.toWavBase64(await SFX.render(EVENTS, window.__duration, {bed:{bpm:100,key:"A",mood:"warm",db:-10}}));
```
- **Звуки:**
  - пролёты: `whoosh`, `swish`, `reverse` (длина и тембр от скорости и размера, панорама по движению на экране);
  - удары: `pop`, `click`, `tick`, `bubble`, `impact`, `thud`;
  - бумага: `paper`, `fold`, `tear`;
  - напряжение и разрядка: `riser`, `downer`;
  - цифровое: `glitch`;
  - блеск: `sparkle`, `chime`;
  - прочее: `type`, `shutter`, `heartbeat`, `drone`.
- **Вариативность встроена:** каждое событие получает свой seed (±4 % высоты, ±1.5 dB), поэтому повторы не звучат копипастой.
- **Музыкальная подложка `bed`** (бочка, хэт, бас, пэд, настроения warm/tense/bright/dark) — запасной вариант, если нет лицензированного трека.
- `render.cjs` сам забирает `window.__audioWav()`, мастерит громкость (`loudness.py`: компрессор → подбор усиления → лимитер с передискретизацией; −14 LUFS, true peak ≤ −1.5 dBTP) и сводит с видео в AAC. **Ничего не воспроизводится вслух:** офлайн-рендер.
- **Слои удара** (атака + тело + хвост) уже внутри `impact`. Для героя-события накладывай 2 звука: материал и воздух.

## 0b. Бесплатные паки и библиотеки (когда процедурного мало)
Музыку с аркой и реалистичный фоли лучше брать из качественных бесплатных библиотек с понятной лицензией для YouTube. Список с проверенными лицензиями — в §6. Правила:
- **Лицензия конкретного файла** проверяется до использования: коммерческое использование на YouTube, нужна ли атрибуция, можно ли раздавать. Источник, автор и лицензия идут в список в конце.
- **Скачивание** — только с разрешения пользователя (имя файла, источник, размер). Файлы кладутся в `audio/sfx/` и `audio/music/`.
- **Музыку подбирай по темпу монтажа:** склейки каждые 2–4 доли. Режь на границах фраз (4/8 тактов). Финал — на сильной доле или на стингере.

## Что нужно ролику
- **Музыка с аркой.** Мотив → развитие → пик → разрядка → финальный акцент. Набор whoosh'ей и ударов композицию не заменяет.
- **SFX на действия по материалу:**
  - бумага — шелест, сгиб, рвётся;
  - пластик — щелчок;
  - металл — звон;
  - воздух — свист пролёта, длина по скорости;
  - UI — тихие клики и «тики».
- Без человеческих голосов в SFX (крики и кряхтение слышатся как мат).
- **Атмосфера-подложка** (room tone, город, ветер): тихо, чтобы мир не был стерильным.

## Где взять
- Музыку и звук можно синтезировать кодом (Web Audio API, офлайн-рендер через `OfflineAudioContext`) или взять из библиотеки с подходящей лицензией. Генераторы — только с разрешения пользователя.
- Для видео нужен **реальный аудиофайл** (WAV), а не звук, который играет в превью: офлайн-рендер → WAV → mux в MP4 (`render.cjs --audio`).
- **Во время работы ничего не воспроизводим вслух:** звук проверяется по файлу (спектрограмма, громкость, акценты), браузерные вкладки заглушены.

## Карта акцентов (синхронизация)
1. Когда дорожка готова, отметь таймкоды заметных акцентов: удар, нота, смена фразы, пауза, возвращение ритма. Пик атаки ищи по огибающей (onset), а не по началу файла.
2. Назначь на выбранные акценты визуальные события: склейку, раскрытие, контакт, конец движения. Не каждый бит — только смысловые точки.
3. Кадр события = `round(время_акцента × fps)`. После speed ramp или обрезки пересчитай.
4. Проверь 5 точек покадрово в финальном MP4 (с учётом смещения аудио после mux).

## Микс (единственный набор чисел; §7 — детали)
- **Сдача:** −14 LUFS integrated, true peak ≤ −1.5 dBTP. Это запас под AAC; `loudness.py` по умолчанию бьёт в −2.
- **Голос:** около −16 LUFS в миксе. Музыка под голосом на −18…−22 dB, на фразах ducking 6–12 dB (атака 30–80 мс, восстановление 250–700 мс).
- Ни клиппинга, ни щелчков на склейках (фейды 2–10 мс), хвост финала не обрезан.
- **Проверка:** `scripts/watch.py` → `audio.json` и `spectrogram.png`.

## 7. Микс: точные значения
- **Ducking:** музыка проседает на 6–12 dB под голосом и ключевыми SFX, атака 30–80 мс, восстановление 250–700 мс.
- **Round robin:** 3–5 вариантов одного звука, высота ±3–5 %, громкость ±1.5 dB. В `sfx.js` это делается автоматически, через seed.
- **Слои героя-события:** атака (0–20 мс) → тело → хвост.
- **Фейды:** ≥ 2–5 мс на каждом клипе.
- **Панорама** следует за x на экране (×0.8); всё ниже 120 Гц в моно.
- **Музыка:** BPM подбирай так, чтобы сцены были целыми тактами. Режь на 4/8-тактных фразах, стингер ставь на сильную долю со звенящим хвостом.
- **Целевая громкость** — см. «Микс» выше: −14 LUFS, true peak ≤ −1.5 dBTP.
