# Характер движения: один архетип на ролик

Выбери **один** архетип по смыслу и бренду и запиши его в карточку плана. Длительности, изинги и перелёты всего ролика берутся из его строки. Смешивание архетипов читается как «собрано из разных роликов».

| Архетип | Для чего | Длительности (база ×) | Изинги | Перелёт (overshoot) | Сжатие-растяжение | Камера |
|---|---|---|---|---|---|---|
| **Премиум** | дорогие продукты, тех-бренды | ×1.3 (медленнее) | `expo.out`, `power3.inOut` | 0 % | нет | длинные плавные проезды, малый дрейф |
| **Уверенный** | B2B, финтех, объяснялки | ×1.0 | `power3.out`, `power2.inOut` | 0–5 % | нет | один чистый жест на план |
| **Дружелюбный** | приложения, сервисы | ×0.9 | `back.out(1.4)`, пружина 250/20 | 5–10 % | 3–6 % | лёгкие акценты |
| **Игривый** | детское, игры, мемы | ×0.8 | `back.out(2)`, пружина 180/12 | 15–25 % | 10–20 % | частые пружинные акценты |
| **Мультяшный** | персонажи, гэги | ×0.7, удержания на позах | пружина 150/10, `elastic.out(1,.5)` | 20–35 % | 15–25 % | рывки на гэгах, замедление на провале |
| **Энергичный / эдит** | вертикаль, музыка, реклама | ×0.6, синхрон с долями | `expo.in` → удар, speed ramp | 10–20 % на ударах | 5–10 % | тряска на ударах, whip-pan |
| **Механический** | инженерия, данные, UI-системы | ×1.0 | `steps(n)`, `power1`, линейные пути | 0 % | нет | прямые проезды по осям |

**Перелёт по материалу** (если архетип допускает перелёт):

| Материал | ζ | Перелёт |
|---|---|---|
| бумага | 0.7 | ≈ 5 % |
| пластик | 0.55 | ≈ 12 % |
| резина / желе | 0.4 | ≈ 25 % |
| металл | 0.85 | ≈ 1 % |

**Перелёт по смыслу:** радость и успех — больше; ошибка и тревога — 0 % и резкая остановка; спокойствие — 0 %.
